# Images de la landing page Terra Sense

Ce dossier est réservé aux photographies Pexels téléchargées et optimisées par Claude lors de la finalisation de la landing page.

Consulter impérativement `../../CLAUDE-PROMPT-PEXELS.md` avant d'ajouter des ressources.

Règles :
- conserver les images localement dans ce dossier (pas de hotlink Pexels dans l'interface finale) ;
- privilégier WebP optimisé ;
- vérifier les conditions d'utilisation affichées par Pexels ;
- enregistrer chaque source et photographe dans `PEXELS-SOURCES.md` ;
- ne jamais présenter une photographie illustrative comme une mesure ou une imagerie satellite réellement analysée par Terra Sense.

Noms de fichiers suggérés :
- `hero-soil-landscape.webp`
- `agriculture-field.webp`
- `ecosystem-savanna.webp`
- `water-resource.webp`
- `satellite-earth-observation.webp`
- `soil-research-fieldwork.webp`
